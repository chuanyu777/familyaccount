# 第三轮：写后自动刷新 · 月份快选 · 资产历史快照（同日傍晚）

用户三类反馈：
1. 新增/删除/编辑后数据不更新（账面数字 / 详情列表不变）
2. 记账的年月想要日历组件快速选择
3. 资产需要「定期更新市值并保留历史」；分析页要支持选月查看历史月份收支、资产、负债

## 解决思路

### 写后刷新（前端）
- 新增 `web/src/lib/revision.ts`：`revision = ref(0)` + `bumpRevision()`
- `lib/api.ts` 的所有 `apiPost/Patch/Put/Delete` 写完后调用 `afterWrite()` = `invalidate()` + `bumpRevision()`
- `cachedGet(path, params, opts)` 增加 `{ force?: boolean }`：跳过缓存直接走网
- 新增 `cacheEpoch` + `invalidate()` 自增：飞行中的 `backgroundRefresh` 看到 epoch 变了就不再写回缓存（修掉"刚删的东西又出现了"的竞态）
- 各页面（记账/资产/负债/分析/设置/App）`watch(revision, () => load({force:true}))`；写后调用方不再需要手动 reload

### 月份快选组件
- `web/src/components/MonthPicker.vue`：左/右箭头按月步进 + 点中间标签弹出**年/月宫格**，含快捷「本月/上月/该年 12 月」
- 未来月份 disabled（默认 max=currentMonth()）
- 接入到记账页（替换原 `‹ 2026年9月 ›`）与分析页

### 分析页支持选月
- 改造为 `month = ref(currentMonth())` + MonthPicker
- 单次请求 `/api/stats/monthly-snapshot?month=YYYY-MM` 拉齐：本月收支、资产负债（当月末）、支出分类占比
- 趋势接口 `/api/stats/monthly-trend?months=6&end=YYYY-MM` 按选中月为终点
- 净资产里 `accountsTotal + assetsTotal` 分开显示；`assetsEstimated: true` 时给「这个月有资产项还没记过市值，暂按当前市值计入」提示

### 资产定期更新 + 历史（后端 + 前端）
- 新表 `asset_snapshot (id, asset_id, month, value_cents, note, recorded_at)`，`UNIQUE(asset_id, month)`
- 服务：`upsertAssetSnapshot / listAssetSnapshots / deleteAssetSnapshot / assetValuesAtMonth / assetsTotalAtMonth`
- 规则：
  - 月份 = 当前月 → 同时把 `asset.value_cents` 同步为该值（这就是最新市值）
  - 月份 < 当前月 → 只写历史快照，不动当前市值
  - 月份 > 当前月 → 400 FUTURE_MONTH
- `createAsset` 建项时自动写当月快照；`updateAsset` 改 value 也写一条当月快照（向后兼容）
- 路由：`POST/GET/DELETE /api/assets/:id/snapshots`、`DELETE /api/assets/snapshots/:snapshotId`（注意路由顺序，`/:id` 之前）
- 历史月份的资产市值 = 该月及之前最近一条快照，缺失回退到当前 value_cents（source='current'，触发 assetsEstimated 提示）

### 历史月份统计反推（无新增表）
- 负债月末余额：`remaining_at_M = remaining_now + Σ(repayment after lastDayOf(M))`；`liability.created_at` 截到月份若晚于 M 则记 0
- 资金账户余额：`accountsTotal_at_M = accountsTotal_now - Σ(txn effects after lastDayOf(M))`（income +, expense -, transfer 0）
  - ⚠️ 已知取舍：`calibrateBalance` 校准账户余额不产生 txn，历史倒推会有偏差
- 月供合计：当时已存在的负债才计入

- 新增：`server/src/domain/month.ts`、`web/src/lib/revision.ts`、`web/src/components/MonthPicker.vue`(+test)、`web/src/features/assets/AssetSnapshotForm.vue`
- 修改：schema.sql、assets.ts/.test.ts、liabilities.ts/.test.ts、stats.ts、asset.routes.ts(+test)、stats.routes.ts(+test)、api.ts(+test)、App.vue、AccountingPage.vue、AnalysisPage.vue(+test)、AssetsPage.vue(+test)、LiabilitiesPage.vue、SettingsPage.vue

## 根因与修正
- 上一轮我把记账页 `handleSaved` 改成**只依赖 `watch(revision)`**，且 revision 监听里调用的是 `resetAndLoad() → load()`（**无 force**）。万一浏览器里 invalidate 清缓存没完全生效（并发写回等），就会读到旧值。
- 修正：**写操作后直接在本组件内 `load({ force: true })` 强制走网络**（记一笔/删一笔的 handleSaved/doDelete），不依赖跨模块 revision 传播；revision 只作兜底（也改成 force）。
- 其余页面（资产/负债/设置）本就在 @saved 里 `load(true)`，未变。
- 结论：本 App 页签切换会重新 mount（App.vue 用 `<component :is>`），跨页数据靠重挂载天然刷新；**同页刷新才是唯一缺口**，用「写后显式 force 重拉」最稳。

## 样式修正
- 根因：`<html lang="zh-CN">` 走 CJK 断行，「-¥999.00」的负号会被当成分隔符折到上一行。
- 修正：`base.css` 给 `.money` 加 `white-space: nowrap`（金额永不折行）。

## 部署步骤（给用户）
1. 服务器装 Docker：`curl -fsSL https://get.docker.com | sh`
2. 上传 backend/ web/ deploy/ package.json package-lock.json tsconfig.json .dockerignore（排除 node_modules/backend/target/server/.git）
3. 设密码：`echo "DB_PASSWORD=xxx" > deploy/.env`
4. `docker compose -f deploy/docker-compose.prod.yml up -d --build`
5. 验证 `curl http://IP/api/family` → 我的家；浏览器访问 http://IP

## 注意
