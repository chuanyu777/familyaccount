# 小程序手工验收清单

## 使用前提

- [ ] **待真实环境验证**：已使用微信开发者工具导入 `mini/`，填入真实 AppID，并完成小程序合法域名/开发设置。
- [ ] **待真实环境验证**：开发后端可从开发者工具或真机访问；`mini/lib/env.ts` 的开发地址为可访问 HTTPS API origin。
- [ ] **待真实环境验证**：后端已配置 `WECHAT_MINI_APP_ID`、`WECHAT_MINI_APP_SECRET`、非空 `SESSION_SECRET`；生产环境另确认 `SESSION_COOKIE_SECURE=true`。
- [ ] **本地可自动检查**：`app.json` 中每个页面路径均对应 `.ts` 和 `.wxml` 文件，页面 JSON 可解析，组件引用路径存在。

除“本地可自动检查”外，本清单的真实环境项目在本次任务中均不预设为通过。不要把未运行微信开发者工具或未连接真实后端的项目改成“通过”。

## 普通用户登录和首次进入

- [ ] **待真实环境验证**：未注册的普通用户从小程序进入，点击唯一的微信登录入口，完成微信登录并到达 `ledger/empty`。
- [ ] **待真实环境验证**：普通用户主按钮直接微信登录，无需选择账号类型、手机号或 Web 凭据；次级“已有 Web 绑定码”仅作为特殊用户支持入口。
- [ ] **待真实环境验证**：没有账本时可进入“创建账本”和“接受邀请”，不会自动创建默认账本。
- [ ] **待真实环境验证**：检查请求认证使用 `ledger_session` Cookie；不能用 `Authorization` 或 `platform_session` 代替。

## 创建、查看和切换账本

- [ ] **待真实环境验证**：普通用户创建账本后成为 `OWNER`，创建出的账本自动成为当前账本。
- [ ] **待真实环境验证**：新账本出现默认账户、基础收入分类和支出分类，且不会带入其他账本的数据。
- [ ] **待真实环境验证**：用户属于多个账本时，账本列表显示所有账本及 OWNER/MEMBER 角色；切换后重新加载记账、账户、资产、负债、分析和设置数据。
- [ ] **待真实环境验证**：用户只有一个账本或选中当前账本时，仍可点击“进入账本”到达主页。
- [ ] **待真实环境验证**：切换账本后，上一账本的列表、筛选和表单数据不会残留；当前账本选择在重新进入小程序后仍符合预期。

## 邀请分享和接受

- [ ] **待真实环境验证**：OWNER 在账本列表或设置中生成邀请，并能通过小程序分享入口分享邀请路径。
- [ ] **待真实环境验证**：另一位未加入该账本的已登录用户打开分享路径，看到邀请详情并明确确认后加入，角色为 `MEMBER`。
- [ ] **待真实环境验证**：邀请过期、撤销、已使用或无效时不会创建成员关系，并显示可理解的错误。
- [ ] **待真实环境验证**：已是成员的用户重复打开同一邀请不会产生重复成员关系。
- [ ] **待真实环境验证**：未登录用户从分享链接进入后，登录完成优先回到同一邀请；已有账本用户也优先看到邀请确认，只有确认后才加入。
- [ ] **待真实环境验证**：无 token 的新用户能从无账本页粘贴口令；页面不展示后端不支持的邀请预览或失效原因细分。

## OWNER/MEMBER 权限

- [ ] **待真实环境验证**：OWNER 可以邀请/移除成员、修改账本名称、归档/恢复共享资源，并可以编辑或删除所有成员创建的交易和还款。
- [ ] **待真实环境验证**：MEMBER 可以查看账本数据，创建和编辑共享资源，创建交易和还款；只能编辑或删除自己创建的交易和还款。
- [ ] **待真实环境验证**：MEMBER 看不到或不能执行邀请、移除成员、账本配置、归档/恢复共享资源等 OWNER 操作；服务端拒绝直接构造的越权请求。
- [ ] **待真实环境验证**：OWNER 不能移除自己，也不能离开自己创建的账本；MEMBER 可以主动离开，历史业务数据仍保留。

## 归档和业务区域

- [ ] **待真实环境验证**：OWNER 归档账户、资产、负债或分类后，历史记录仍可查看，资源从新的交易、快照或还款选择中移除。
- [ ] **待真实环境验证**：对已归档资源发起新的关联写入会被后端拒绝且不产生部分更新；OWNER 恢复后可重新使用。
- [ ] **待真实环境验证**：在同一当前账本内，记账、资产、负债/还款、分析和分类功能都能打开并显示当前账本数据。
- [ ] **待真实环境验证**：记录超过一页时能加载更多；切月/类型后重置首屏，续页失败保留旧列表并可重试。
- [ ] **待真实环境验证**：OWNER/MEMBER 均能校准活动账户的负数、零和正数余额；归档账户无校准入口，跨账本写入被拒绝，校准不生成交易。
- [ ] **待真实环境验证**：归档资产的“市值历史”可读，错误不展示另一资产的旧记录；恢复后才可新增市值。
- [ ] **待真实环境验证**：中国本地午夜后新交易/还款默认当天；账户和分类选择显示真实名称；分类 12345 分显示 ¥123.45。

## 特殊 Web 绑定（次级支持入口）

- [ ] **待真实环境验证**：登录页的次级“已有 Web 绑定码”和设置中的“绑定 Web 账号”可达；无账本引导不要求绑定，普通用户始终使用主微信登录按钮。
- [ ] **待真实环境验证**：预置特殊账本用户先在 `/ledger` Web 端生成一次性绑定码，再在首次普通微信登录之前从支持入口完成绑定；请求只调用 bind，不能先调用普通 login。
- [ ] **待真实环境验证**：绑定成功后进入原有特殊账本；绑定码过期、重复使用或微信身份已属于其他用户时不改变任何身份关系。
- [ ] **待真实环境验证**：小程序普通登录和特殊用户绑定后的请求都使用 `ledger_session` Cookie；平台管理员的 `platform_session` 不能访问账本写接口。

## 强制退出和移除成员

- [ ] **待真实环境验证**：OWNER 移除 MEMBER 后，成员当前页面的后续账本请求立即得到未授权结果并回到账本列表或登录入口，不继续展示可写的旧账本状态。
- [ ] **待真实环境验证**：被移除成员重新登录或刷新后不能访问该账本；其他账本和已保存的非账本会话行为符合预期。
- [ ] **待真实环境验证**：成员主动离开后同样失去该账本访问权；交易、还款和共享资源历史没有被物理删除。
- [ ] **待真实环境验证**：注销只清除 `ledger_session`，重新登录后按用户的账本状态进入列表或无账本页。
