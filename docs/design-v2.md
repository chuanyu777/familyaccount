# 家庭记账簿 · 视觉规范 v2（燕麦焦糖）

> 状态：待确认。确认后按本文档改造 `web/`，不改接口、不改路由。
> 基线：方向 D 骨架（大圆角卡片/胶囊/泡泡）× P2 燕麦焦糖配色 × 衬线标题 + 黑体正文。

## 0. 设计概念

**一句话**：一本摆在木桌上的暖色活页账——纸感暖白做底，焦糖橙是"蘸水笔"的颜色，只出现在操作和强调处；钱本身永远是红（支出）绿（收入）。

**三条原则**

1. **圆**：卡片 ≥14px 圆角、按钮胶囊、图标泡泡——亲和、无攻击性。
2. **静**：一屏只留一个视觉重心（结余大数字）；其余信息降噪（灰、细、小）。
3. **快**：高频动作（记一笔）永远在拇指区；所有点击热区 ≥44px。

## 1. 设计令牌（Design Tokens）

### 1.1 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#FAF9F6` | 页面底色（暖白纸感） |
| `--surface` | `#FFFFFF` | 卡片/弹层表面 |
| `--surface-2` | `#FAEEDA` | 浅强调面（选中态背景、日期胶囊） |
| `--ink` | `#3A352C` | 一级文字 |
| `--ink-2` | `#948B78` | 二级文字/提示 |
| `--ink-3` | `#C9C2B2` | 占位/禁用 |
| `--brand` | `#854F0B` | 主色：主按钮、选中态、FAB（焦糖深橙） |
| `--brand-2` | `#BA7517` | 主色亮色：图标泡泡内图形、链接 |
| `--brand-wash` | `#FAEEDA` | 主色洗涤底 |
| `--expense` | `#993C1D` | 支出文字（深红） |
| `--expense-wash` | `#FAECE7` | 支出泡泡底 |
| `--income` | `#3B6D11` | 收入文字（深绿） |
| `--income-wash` | `#EAF3DE` | 收入泡泡底 |
| `--line` | `#EDE8DC` | 卡片描边/分隔线 |
| `--danger` | `#A32D2D` | 删除等破坏性操作 |
| `--mask` | `rgba(58,53,44,0.36)` | 弹层遮罩 |

约束：**支出红与收入绿不可互换**（中国习惯）；主色焦糖不得用于金额。

### 1.2 字体

- **标题/家庭名/大结余数字**：衬线栈 `"Noto Serif SC", "Songti SC", "STSong", serif`，weight 500–600。
- **正文/列表/表单**：黑体栈 `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`，weight 400/500。
- **列表金额/键盘数字**：黑体 + `font-variant-numeric: tabular-nums`（等宽数字，防跳动）。
- 字阶（px）：11 辅助 / 12 次级 / 13 正文 / 15 卡片标题 / 17 区块标题 / 22 结余大数 / 28 记一笔金额。

### 1.3 间距 / 圆角 / 阴影 / 动效

- 间距：4 的倍数 —— `4, 8, 12, 16, 20, 24, 32`；页面左右边距 16，卡片内边距 14–16。
- 圆角：`--r-sm: 10px`（泡泡）/ `--r-md: 14px`（卡片）/ `--r-lg: 20px`（弹层顶部）/ `--r-pill: 999px` / `--r-full: 50%`。
- 阴影：仅两级，都要"贴地"：
  - `--shadow-card: 0 1px 2px rgba(58,53,44,0.05)`
  - `--shadow-pop: 0 -8px 24px rgba(58,53,44,0.12)`（底部弹层）
- 动效：`--dur-fast: 150ms` / `--dur: 250ms` / `--dur-slow: 350ms`；缓动 `cubic-bezier(0.2, 0.8, 0.2, 1)`；尊重 `prefers-reduced-motion`。

## 2. 组件规范

### 2.1 顶部栏（每页统一）
- 左：家庭名（衬线 17px，`--ink`）；右：页面相关的唯一操作（如记账页的月份胶囊）。
- **月份胶囊**：`--surface-2` 底、`--brand` 字、pill 形，`9月 ▾`，点击弹底部抽屉（复用现有 MonthPicker，改成抽屉样式）。
- 高度 56px，下方无分隔线（用留白区分）。

### 2.2 结余统计卡（记账页/分析页共用）
- 白卡 `--r-md` + `--shadow-card`，左侧：辅助文字"这个月还剩" + 衬线 22–28px 结余（正数绿、负数红）。
- 卡内底部两个泡泡：收入泡泡（`--income-wash` 底 / `--income` 字）、支出泡泡（`--expense-wash` 底 / `--expense` 字），各 10px 圆角、flex:1。
- 右侧可放迷你环形进度（支出/收入比），直径 52px，线宽 3px——纯装饰，无数据时不渲染。

### 2.3 流水行（列表项）
- 每条一张白卡：`--r-md`、卡片间距 8px、内边距 11–12px。
- 结构：`图标泡泡 34px`（收入/支出各用 wash 底 + 主图形色块）→ `分类名 13px + 备注·成员 11px --ink-2` → `金额 tabular-nums 13px 500`（支出 `--expense` / 收入 `--income`，带符号）。
- 点击整行进详情弹层；**行上不裸露编辑/删除按钮**（收进详情弹层，沿用现有约定）。
- 日期分组：左对齐小胶囊（`--surface-2` 底、`--ink-2` 字、11px），文案「今天 · 9月14日」「昨天 · 9月13日」「9月12日 周五」。

### 2.4 FAB「记一笔」（记账页专属）
- 右下固定：`right: 20px; bottom: calc(64px + env(safe-area-inset-bottom))`，直径 48px 圆形 `--brand`，白色「+」（24px）。
- 按下缩放 `transform: scale(0.94)`，150ms 回弹。

### 2.5 底部导航（5 Tab，加图标）
- 高 64px + 安全区；白底、顶部 1px `--line`。
- 每项：24px 线性图标（1.5px 描边，圆角线帽）+ 11px 文字；选中 = `--brand` + 图标描边加粗至 2px；未选中 = `--ink-2`。
- 图标清单（建议线性 SVG 自绘，不用图标库）：
  - 记账：钢笔尖/账本方框 + 一横
  - 资产：钱包（方块 + 圆点）
  - 负债：银行卡（矩形 + 磁条横线）
  - 分析：三根高低柱状
  - 设置：齿轮

### 2.6 按钮体系
- 主按钮：`--brand` 底白字，高 44px，pill，15px 500；按下明度 -8%。
- 次按钮：白底 `--line` 描边 `--ink` 字，同高 pill。
- 危险：`--danger` 字 + `--expense-wash` 底（仅确认弹层内）。
- 幽灵：无边框 `--brand-2` 字，用于"加载更多"等低频。

### 2.7 底部弹层（Bottom Sheet，替代现有居中弹层）
- 从底部升起：顶部圆角 `--r-lg`、顶部居中 36×4px 抓手条（`--ink-3`）、遮罩 `--mask`。
- 动画：`transform: translateY(100%) → 0`，250ms 缓动；下滑手势可关闭（可后置实现）。
- 用途：记一笔表单、流水详情、月份选择、确认删除。

### 2.8 记一笔表单（本次重点重设计）
布局自上而下（全部在底部弹层内，弹层高度 ≈ 85% 屏高）：

1. **类型分段**：支出 / 收入 / 转账 三枚胶囊，选中 `--brand` 底白字。
2. **金额区**：超大 28px tabular 数字居中，前缀 ¥，光标闪烁；未输入时占位 `0.00`（`--ink-3`）。
3. **分类宫格**：4 列网格，每格 = 泡泡图标 + 11px 名称；选中格外圈 `--brand` 2px 描边 + wash 底；支出/收入分类集不同（沿用现有接口）；宫格底部放「＋ 新分类」虚线格。
4. **属性 chips**：账户、成员、日期（默认今天）三枚 pill 一排，可横向滚动；点日期弹滚轮/日历。
5. **备注**：单行输入，占位「写点什么…（可不填）」。
6. **数字键盘**：3×4 栅格占满弹层宽度，键高 56px；键位 `1-9`、`.`、`0`、`⌫`，右侧贯通两行的「完成」主色键（无金额时文案「完成」置灰禁用）。
7. 行为：输完金额点分类即完成可选项最小化——**金额 + 分类即可保存**；保存后 Toast「已记一笔」并自动收起弹层、列表滚动到最新条。

### 2.9 详情弹层（流水/资产/负债通用）
- 顶部：大金额（衬线 22px）+ 分类名；下方 dl 列表（账户、成员、日期、备注）。
- 底部两个按钮：次按钮「编辑」、危险按钮「删除」（删除需二次确认弹层，文案具体化：「删除这笔 ¥35.00 的餐饮支出？」）。

### 2.10 状态三件套（每页必须覆盖）
- **空状态**：居中 64px 线稿插图位（占位色块即可）+ 13px 文案 + 主按钮引导（如「记第一笔」）。
- **加载**：骨架屏（卡片形灰色呼吸块，1.2s），不用 spinner。
- **错误**：卡片内错误文案 + 「重试」次按钮。

### 2.11 Toast
- 底部居中黑底（`--ink` 90%）白字胶囊，12px，停留 1.6s，上飘 8px 淡入。

## 3. 页面规范（5 页）

### 3.1 记账
顶部栏（家庭名 + 月份胶囊）→ 结余统计卡 → 筛选 chips（全部/支出/收入/转账，选中 `--brand` 底白字；更多筛选收进弹层）→ 日期胶囊分组 + 流水行卡 → FAB。首屏必须露出 ≥3 条流水。

### 3.2 资产
顶部「资产」标题 + 总览卡（净资产衬线大数 + 资产/负债两泡泡）→ 分组列表卡（资金账户组、固定资产组，组头 12px `--ink-2`）→ 行尾金额右对齐 tabular。行点击进详情（含「更新市值」主按钮 + 历史快照列表卡）。

### 3.3 负债
总览卡（总负债衬线大数 + 月供泡泡）→ 负债行卡：名称 + 剩余本金大数 + 进度条（已还比例，`--brand-2` 填充、`--surface-2` 底，高 6px pill）+「还一笔」小胶囊按钮（行内唯一高频操作）。

### 3.4 分析
月份胶囊 → 结余统计卡（同 3.2 组件）→ 趋势卡（近 6 个月柱状：支出 `--brand-2`、收入 `--income` 洗色，圆角柱 4px）→ 分类占比卡（横向条形 + 百分比，最多 6 类 + 其他）。无数据走空状态。

### 3.5 设置
分区白卡列表（家庭 / 成员 / 分类管理 / 数据），行高 48px，右箭头 `--ink-3`；危险区（如清空数据）单独卡片、`--danger` 文案。

## 4. 动效规范

| 场景 | 动效 | 参数 |
|---|---|---|
| Tab 切换 | 内容淡入 + 上移 8px | 200ms，无左右滑动（避免误触返回手势） |
| 底部弹层 | 升起 / 落下 | 250ms `cubic-bezier(0.2,0.8,0.2,1)` |
| 保存流水后 | 新行卡淡入 + 列表自动滚至顶部该行 | 200ms |
| 数字变化 | 统计卡数字 tabular 直接替换，不做滚动动画 | — |
| 按下反馈 | 按钮/卡片 `scale(0.97)` 或明度 -8% | 150ms |
| 全局 | `prefers-reduced-motion: reduce` 时全部禁用 | — |

## 5. 移动端与可访问性硬性指标

- 热区：所有可点元素 ≥ 44×44px（流水行、Tab、chips、键盘键均达标）。
- 对比度：正文 ≥ 4.5:1（`--ink`/`--ink-2` 在 `#FFFFFF`/`#FAF9F6` 上均达标；`--ink-3` 仅用于装饰与占位，不承载信息）。
- 安全区：底部导航与 FAB 均加 `env(safe-area-inset-bottom)`。
- 断点：以 360–430px 手机为设计基准；≥768px 时内容居中限宽 480px（不另做桌面布局）。
- 键盘弹起：记一笔弹层高度用 `dvh`，避免被系统键盘顶飞（自定义数字键盘为主，系统键盘仅备注框唤起）。
